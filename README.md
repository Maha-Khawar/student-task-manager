# student-task-manager

A simple console Student Task Manager built with Python.

Project status: In Progress

## Features
- Add tasks (empty titles are rejected)
- Display tasks
- Mark tasks as completed
- Delete tasks by ID

## Setup
1. Install Python 3.
2. Clone the repo: git clone https://github.com/Maha-Khawar/student-task-manager.git
3. Open the project folder.

## Usage
Run: python task_manager.py
Choose an option from the menu (1 Add, 2 Display, 3 Complete, 4 Delete, 5 Exit).

## Running tests
Run: python -m unittest discover -s tests -v
