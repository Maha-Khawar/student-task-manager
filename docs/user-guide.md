# User Guide

1. Run `python task_manager.py`.
2. Choose 1 to add a task and type a title. Empty titles are rejected.
3. Choose 2 to list tasks. Completed tasks show [x].
4. Choose 3 and enter a task ID to mark it completed.
5. Choose 4 and enter a task ID to delete it.
6. Choose 5 to exit. Tasks are kept in memory only, so they are cleared on exit.
